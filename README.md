# Архитектурный паспорт my.adapt

Практическая работа №3 по дисциплине «Создание клиент-серверных приложений».

my.adapt — мобильная игра для знакомства студентов с ИТМО. Игрок открывает локации по QR-коду, ищет предметы на панорамах и собирает информационные карточки. Прогресс хранится на устройстве. Общий рейтинг доступен в игре и на сайте.

## Как связаны файлы

Схема C4 показывает, как игра обращается к серверу. OpenAPI уточняет, что она передаёт и какой ответ получает. По ER-диаграмме можно увидеть, как рекорд и квитанция связаны с участником и раундом. JWT и обработка повторных запросов описаны в проектном контракте.
